# Observatory identity

The primary interface mark is the supplied blue-eye artwork. It is stored as `public/brand-eye-poster.jpg` and rendered only in the top-left header beside the badBANANA / THREAT OBSERVATORY wordmark.

No synthetic motion is applied to the static artwork. The footer, favicon, Open Graph metadata, evidence cards, backgrounds, and other application surfaces retain their existing independent behavior and do not reuse the eye asset.

The header mark uses the approved responsive dimensions: 76×76 px on desktop, 68×68 px at 900 px and below, 64×64 px at 700 px and below, and 60×60 px at 560 px and below.
