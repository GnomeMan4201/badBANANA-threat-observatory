# Observatory identity

The primary interface mark is the supplied animated blue-eye artwork. The production asset is stored as `public/brand-eye.gif` and rendered in the top-left header beside the badBANANA / THREAT OBSERVATORY wordmark. The README uses the same artwork as its opening visual.

The animation comes from the supplied source artwork; the application does not synthesize replacement eye motion with CSS or vector redraws. GitHub may pause animated images for viewers who disable motion or autoplay.

The header mark uses the approved responsive dimensions: 76×76 px on desktop, 68×68 px at 900 px and below, 64×64 px at 700 px and below, and 60×60 px at 560 px and below.
